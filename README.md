# praxis101-net

The archive home for Praxis101 work, blogs, and resources.

Built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/). The layout
is a reimplementation of the site's original [Skeleton](https://github.com/dhg/Skeleton) design —
same 800px column, typography and breakpoints, none of the framework.

Live at <https://band.github.io/praxis101-net/>, deployed from `main` by GitHub Actions.
The intended home is praxis101.com; see [plan.md](plan.md).

```sh
npm install
npm run dev      # http://localhost:4321/praxis101-net
npm run build    # -> dist/
```

Requires Node >= 22.12.
